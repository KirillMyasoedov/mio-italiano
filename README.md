# Il mio italiano

Разговорник с интервальным повторением и свободной тренировкой.

## Бесплатные уведомления для GitHub Pages

Приложение остаётся на GitHub Pages; напоминания выполняет Cloudflare Workers
Free. Нужен аккаунт Cloudflare и Node.js 22 или новее. Vercel Hobby для
минутных напоминаний не подходит: его встроенный Cron запускается раз в сутки.

```sh
npm ci
npm run push:check
npm run push:login
npm run push:deploy
```

Вход выполняется в браузере Cloudflare. Платный тариф, покупка домена и VPS
не нужны. Используются SQLite-backed Durable Objects, доступные на Workers Free.
В бесплатном плане превышение квот останавливает операции до сброса лимита,
а не включает платный тариф автоматически. Для личного разговорника нагрузка
невелика: объект просыпается при изменении расписания и к ближайшему сроку.
Не подключайте Workers Paid для этого проекта.

Сервер этого проекта опубликован по адресу
`https://mio-italiano-reminders.mio-italiano.workers.dev`; он уже указан в
`push-config.js`. После обновления GitHub Pages вводить адрес вручную не нужно.

При самостоятельной публикации Wrangler покажет HTTPS-адрес вида
`https://mio-italiano-reminders.<ваш-поддомен>.workers.dev`.
В разговорнике откройте «Добавить» → «Напоминания о повторении» →
«Подключение сервера напоминаний», вставьте адрес, нажмите «Подключить сервер»,
затем «Включить уведомления». Нажмите «Проверить через 10 секунд» и закройте
приложение. На iPhone приложение должно быть добавлено на главный экран.

Чтобы не вводить адрес на каждом устройстве, задайте его в `push-config.js`
и опубликуйте обновление на GitHub Pages. В этом файле хранится только публичный
адрес; закрытых ключей в репозитории нет. При обновлении установленного приложения
дайте ему загрузить новую версию, затем закройте и откройте его заново.

В `wrangler.jsonc` параметр `ALLOWED_ORIGIN` — точный origin сайта (без пути
`/mio-italiano/`), сейчас `https://kirillmyasoedov.github.io`. Для другого домена
замените его перед публикацией. Worker разрешает запросы браузера только с этого
origin. У каждого устройства собственный случайный токен и изолированное
хранилище. Ключи VAPID генерируются автоматически для устройства и хранятся
в Durable Object; менять их при повторной публикации не нужно.

Наступившие сроки объединяются в одно уведомление. Следующие сроки сохраняются
и срабатывают без открытого приложения. Одинаковое уже обработанное расписание
не вызывает повторных уведомлений. При временной ошибке отправка повторяется
с увеличивающейся задержкой, недействующие подписки удаляются. Отключение
напоминаний удаляет подписку и расписание, сохраняя ключ для повторного включения.
Только сроки и push-подписка передаются на сервер; тексты фраз остаются на устройстве.
При офлайн-изменениях сервер использует прежние сроки до следующей синхронизации.
Интернет, энергосбережение и настройки ОС могут задерживать доставку.

Официальные ограничения:
[Cloudflare Free](https://developers.cloudflare.com/durable-objects/platform/pricing/),
[таймеры](https://developers.cloudflare.com/durable-objects/api/alarms/),
[Vercel Cron](https://vercel.com/docs/cron-jobs/usage-and-pricing).

## Альтернатива: собственный Node.js-сервер

Если есть постоянно работающий сервер с постоянным диском:

```sh
npm ci
VAPID_SUBJECT=mailto:you@example.com npm start
```

Откройте http://localhost:3000. Для телефона разместите сервер за HTTPS-прокси
на том же домене, что и приложение. Прокси должен передавать `/api/*` этому
серверу. Статический хостинг (например, GitHub Pages) сам уведомления не отправляет.
В настройках приложения нажмите «Включить уведомления». На iPhone сначала
добавьте приложение на главный экран.

Переменные: `PORT` (3000), `HOST` (127.0.0.1), `DATA_DIR` (./data),
`VAPID_SUBJECT` (контакт администратора: mailto: или HTTPS).
Сервер должен работать постоянно; используйте один экземпляр с постоянным диском.
Сохраняйте каталог `data`: в нём ключи VAPID и подписки. Не публикуйте его.
Потеря ключей потребует повторного включения уведомлений на устройствах.

Тексты фраз остаются в браузере. На сервер передаются подписка устройства и
временные метки повторений. Каждые 5 секунд сервер проверяет сроки, объединяет
уже наступившие сроки в одно уведомление и помечает их доставленными после
принятия push-сервисом. Позднейшие сроки продолжают работать при закрытом
приложении. Интернет, энергосбережение и настройки ОС могут задерживать доставку.
Отключение уведомлений удаляет серверную запись. Просроченные подписки удаляются
после ответа 404/410 от push-сервиса. Новые фразы без срока не вызывают уведомлений.
Изменения расписания офлайн передаются при возвращении подключения, пока приложение открыто,
или при следующем открытии; до синхронизации сервер использует прежние сроки.

## Тренировка

«Потренироваться без изменения графика» запускает случайную очередь.
Вес забытых фраз — 8, сложных — 4, вспомненных — 2, остальных — 1.
Текущая фраза не повторяется сразу, если есть другие. «Легко» исключает фразу
до конца сессии; остальные оценки возвращают её в очередь. Сессия завершается,
когда все её фразы отмечены как «Легко». Фразы с тремя последовательными
оценками «Легко» в плановом повторении пропускаются; другая плановая оценка
сбрасывает эту серию. Тренировка не меняет график или сохранённый прогресс.
Старые словари и JSON-копии совместимы; новые поля получают значения по умолчанию.
