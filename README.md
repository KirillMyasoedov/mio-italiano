# Il mio italiano

Разговорник с интервальным повторением и свободной тренировкой.

## Запуск с push-уведомлениями

Нужен Node.js 20 или новее:

```sh
npm ci
VAPID_SUBJECT=mailto:you@example.com npm start
```

Откройте http://localhost:3000. Для телефона разместите сервер за HTTPS-прокси
на том же домене, что и приложение. Прокси должен передавать `/api/*` этому
серверу. Статический хостинг (например, GitHub Pages) сам уведомления не отправляет.
В настройках приложения нажмите «Включить уведомления». На iPhone сначала
добавьте приложение на главный экран.

Переменные: `PORT` (3000), `HOST` (127.0.0.1), `DATA_DIR` (./data),
`VAPID_SUBJECT` (контакт администратора: mailto: или HTTPS).
Сервер должен работать постоянно; используйте один экземпляр с постоянным диском.
Сохраняйте каталог `data`: в нём ключи VAPID и подписки. Не публикуйте его.
Потеря ключей потребует повторного включения уведомлений на устройствах.

Тексты фраз остаются в браузере. На сервер передаются подписка устройства и
временные метки повторений. Каждые 5 секунд сервер проверяет сроки, объединяет
уже наступившие сроки в одно уведомление и помечает их доставленными после
принятия push-сервисом. Позднейшие сроки продолжают работать при закрытом
приложении. Интернет, энергосбережение и настройки ОС могут задерживать доставку.
Отключение уведомлений удаляет серверную запись. Просроченные подписки удаляются
после ответа 404/410 от push-сервиса. Новые фразы без срока не вызывают уведомлений.
Изменения расписания офлайн передаются при возвращении подключения, пока приложение открыто,
или при следующем открытии; до синхронизации сервер использует прежние сроки.

## Тренировка

«Потренироваться без изменения графика» запускает случайную очередь.
Вес забытых фраз — 8, сложных — 4, вспомненных — 2, остальных — 1.
Текущая фраза не повторяется сразу, если есть другие. «Легко» исключает фразу
до конца сессии; остальные оценки возвращают её в очередь. Сессия завершается,
когда все её фразы отмечены как «Легко». Фразы с тремя последовательными
оценками «Легко» в плановом повторении пропускаются; другая плановая оценка
сбрасывает эту серию. Тренировка не меняет график или сохранённый прогресс.
Старые словари и JSON-копии совместимы; новые поля получают значения по умолчанию.
